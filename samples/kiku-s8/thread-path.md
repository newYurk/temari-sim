## Соглашения (b)

- Рабочий полюс смотрит на мастера; линии L0…L7 нумеруются **против часовой стрелки** при взгляде снаружи на полюс; ход обхода = +φ. Основание: GT14 «Move 1 marking line to the right», EAGLE «против часовой стрелки», OLY «右隣の地割り糸». (a) для направления, (b) для нумерации.
- Левша — зеркально (b; источники о левшах не найдены).
- «Слева / справа» — относительно хода (+φ = «справа»).
- Видимое плечо между стежками в модели — дуга большого круга (геодезическая); это идеализация натянутой нити (см. geometry.md §7, model/spec.md §Ф3).

- Старт у **нижней** точки (ピンクピン), первый стежок — верхний на соседней линии справа: «右隣の地割り糸、赤ピンから3〜4mmの所». (a) OLY-TM7-L/V

- Смена цвета по 段: новая нить «ピンクピンの糸の少し下». (a)
- Натяжение: «糸を少し緩ませて、花びらの丸みを意識しながら» — лепесток округлый, плечо **не** геодезическое. (a)
- 16 делений ⇒ 16 лепестков; финал у 水色ピン (7 мм от экватора), затем оби. (a)

## Где мой путь расходится с prior-проектом

- **Число рядов / нижний шаг.** Их `capacity=10` получен из фиксированных 2 мм; сами они признали это арифметикой (#106 f325637). Мой расчёт по «pack then pierce» даёт 4 ряда на набор при C = 240 мм; при 2 мм — 11, но с нахлёстом у кончика по геодезической модели (geometry.md §6). Противоречие с фото GT14 (на фото больше рядов) отмечено как главный открытый вопрос (uncertainties.md U1).
- **Верхняя точка.** У них верх колют «прямо под прежним верхним стежком по линии» (#100). У меня — то же (s_top += w). Совпадает.
- **Одна или две нити.** GT14 и prior — две нити A/B; Olympus/EAGLE/MYJULIA — одна нить. Я держу GT14 и записываю вариант.
