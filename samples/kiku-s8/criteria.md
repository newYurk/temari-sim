# Критерии качества кику S8 (проверяемые)

Каждый критерий: формулировка → основание → как проверять (на модели / на образце) → порог (с пометкой [A], если число моё).

| # | Критерий | Основание | Проверка на модели (calc.py / stage 2) | Проверка на образце | Порог |
|---|---|---|---|---|---|
| K1 | 8 лепестков, два набора по 4, чередуются | TK-KIKU, SAN-KIT007 | число нижних точек на наборе = 4, сдвиг наборов 45° | фото с полюса | точно |
| K2 | Кончики одного ряда на одной параллели | симметрия мотива (TK-GT14 фото) (b) | разброс s_bot в ряду | линейка от экватора | ≤ 1 мм [A] |
| K3 | Верхние точки равномерно вокруг полюса | TK-KIKU | разброс s_top | линейка | ≤ 0,5 мм [A] |
| K4 | Ряды параллельны, соседние ряды на расстоянии ≈ толщины нити, без зазоров | TK-GT14 «parallel», OLY-TM7-V «並べるように糸を置き», SAN-ABOUT «糸が重ならないように» | расстояние по нормали 0,8w…1,5w в теле лепестка (calc §4.2) | ширина полосы N рядов / N | [A] 0,8w…1,5w |
| K5 | У верхних точек плотно, без просветов; у низа не тесно | OLY-TM7-V ~3:36–3:54 | зазор между захватами у верха ≤ 0 (перекрытие допускается — uwagake) | фото крупно | качественно |
| K6 | Верхний стежок ряда n≥2 охватывает все прежние нити своего набора у этой точки | TK-UWA, TK-GT14, SUESS; prior #104/#105 (не пройдено в prior) | топологическая проверка: для каждой ветви из списка over — она внутри петли захвата | крупное фото сбоку | точно |
| K7 | Нить на верхнем подходе идёт ПОВЕРХ прежних рядов | TK-GT14, TK-UWA | порядок над/под по хронологии (prior #102) | фото | точно |
| K8 | Прокол между нитями, не сквозь нить | prior #105 (GT16/GT14) | расстояние точки прокола до оси любой уложенной нити ≥ r_eff | лупа | ≥ r_eff [A] |
| K9 | Разметка не сдвинута, шар не деформирован | TK-KAGARI | равнодействующая в стежке вдоль линии (calc §8.2): боковая сила ∝ ε — ε мало | отклонение 地割り ≤ 1 мм [A] | ≤ 1 мм [A] |
| K10 | Нет провисания нити | TK-KAGARI | в модели плечо в контакте с опорой (T>0) | на ощупь/сбоку | качественно |
| K11 | Концы скрыты, узлов не видно, нет «bleed through» | TK-ANCHOR, OLY-BASIC | операции start/finish присутствуют у каждой нити | осмотр | точно |
| K12 | Кончики до экватора (GT14) / до 水色ピン (Olympus) | TK-GT14 / OLY-TM7-L | последний s_bot ≤ Q | линейка | ≤ 2 мм до границы [A] |
| K13 | Один непрерывный материальный путь на нить; длина u монотонна | архитектура (prior #112) (b) | сумма длин участков = u_end; нет разрывов/телепортаций между рядами (resume в выходной точке) | взвешивание нити до/после | точно (модель) |
| K14 | Отсутствие взаимопроникновения нитей конечной толщины | физика; prior #94 | минимальное расстояние осей ≥ сумма полутолщин (сжатых) | — | ≥ 0 [A] |
