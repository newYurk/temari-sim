## 7. Ограничения модели

- Плечо = геодезическая: допустимо для натянутой нити на гладкой выпуклой поверхности без трения (TK-KAGARI: «moderate tension», «straight»). НЕ годится для OLY-TM7, где нить намеренно ослабляют ради округлости лепестка («糸を少し緩ませて»).
- Толщина нити и слоёв не входит в радиус (нить лежит на сфере радиуса R; реальные слои ~0.4–0.7 мм).
- Верхняя зона uwagake (перехлёст, «клин») моделируется только ростом ширины захвата.
- Подъём/смещение нити при затяжке, трение, упругость — не моделируются.
## 8. Физический слой (соотношения; численно — только в долях T)

### 8.1 Нормальное давление натянутой нити на сферу: p = T·κ_n, κ_n = 1/R для любого направления на сфере

- p/T = 1/R = 0.0262 мм⁻¹. Для плеча длиной ℓ полная нормальная сила N = T·ℓ/R (угол поворота нити = ℓ/R). Плечо ряда 1 (≈37.5 мм): N ≈ 0.98·T.
- Численное значение T (Н) НЕ известно: требуется измерение динамометром (см. uncertainties.md).

### 8.3 Трение в стежке (капстан, Euler–Eytelwein): T_2/T_1 ≤ e^{μθ}

θ — суммарный угол охвата нити в захвате (вниз в обмотку, под линией, вверх, поворот в плоскости). Геометрия захвата внутри обмотки не измерена; θ ∈ [π, 2π] — диапазон-допущение [A].

| μ (источник) | θ = π | θ = 1.5π | θ = 2π |
|---|---|---|---|
| 0.32 (cotton spun yarn–yarn, compact finished (PHYS-COTTON-MU)) | 2.7 | 4.5 | 7.5 |
| 0.52 (cotton spun yarn–yarn, OE dyed (PHYS-COTTON-MU)) | 5.1 | 11.6 | 26.2 |

Смысл: каждый стежок может удерживать перепад натяжения в несколько раз, поэтому натяжение уже уложенных плеч НЕ равно силе, с которой мастер тянет иглу, и определяется историей затяжки (гистерезис). Этим же объясняется OLY-BASIC: игла против хода увеличивает охват -> «糸が抜けにくくなります». μ для Perle #5 (мерсеризованная опалённая 2-сложная) по нити и по обмотке НЕ найдены.
