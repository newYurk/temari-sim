## Formulas (§7)

- s₀ = T/(kR); λ_T = √(T/k); λ_B = (4B/k)^¼; ℓ_b = √(B/T); Π = T/(2√(Bk)).
- t_c(F) = 0.491 − 0.068·ln(0.244·F[gf]) mm (pearl #5; scaled by h/0.464 for another laid height, (c)).
- δ = F/(2√k·√(T + 2√(Bk))); d_low = δ + (h − t_c)/2.
- Δ₁ = 1.5·t_c − h/2 − δ; F = 2T·σ; σ = x₀/R + √(s₀/R); x₀ = √(R(2Δ₁ − s₀)) − √(R s₀); a ≈ √(2RΔ₁).
- u(x) = Δ₁ − σ|x| + x²/2R (|x| ≤ x₀), s₀·e^{−(|x|−x₀)/λ_T} beyond; rigid limit Δ₁(1 − |x|/a)².
- Bridge: u = Δ_i + (Δ_j − Δ_i)·x/L − x(L − x)/2R if ≥ 0; condition L ≤ √(8RΔ).
- ΔL₁ ≥ (4/3)·Δ₁·σ (full: crest + flights + tails); Δ(m) = Δ₁(1 + κ(m − 1)); Δ_cap(m) = (m + ½)·t_c − h/2.
- Support (v1.1): z_sup = u_L,loaded(y_c) − sag, sag = 2σ_U·ab/(a + b); flight kink u_L(x) → max(0, u_L(x) − 2σ_U·(x − y)); Δ_c = z_sup + Δ₁(F_c), F_c = 2Tσ_U; κ only inside the contact patch.
- K18: Δ_c − z_sup ≤ 1.5·t_c(F_c) − h/2; K19: max Δ_c printed, warn > 1.2 mm.
- ρ_c = (w_c/2)²/(t_c/2), w_c = w·h/t_c; ℓ_p = min(σρ_c/sin²ψ, w_c/(2 sin ψ), max(w_c/2, c.lenMm/2)); ψ* = asin(2σρ_c/w_c).
