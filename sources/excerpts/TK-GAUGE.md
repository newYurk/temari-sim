# TemariKai: Thread Gauges

URL: https://www.temarikai.com/ResourcesPages/threadgauges.html

Открыто: 2026-09-24 (исполнитель stage 1). Строки без пометки «(пересказ)» — дословные фрагменты (многоточие = пропуск).

- DMC Perle 5 - 7 threads = 0.5cm
- (пересказ) Пример на той же странице «10 rows … about .75cm» → 0.75 мм/нить; внутреннее расхождение с 0.714 мм.
