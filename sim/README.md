# Симулятор нити темари — этапы 2a/2b/2c (кику S8: A1 → B1 → A2)

Статическое браузерное приложение (HTML + ES-модули + three.js r169, копия в `vendor/three/`, сборки нет).
Строит **явный путь рабочих нитей (A и B)** из рецепта и параметров, проверяет его валидаторами и показывает в 3D.
Механики (равновесие, трение, сжатие) на этом этапе **нет**: плечи — геодезические (идеализация натянутой нити,
model/spec.md Ф3), слои в перекрестах не поднимаются (этап 2.4).

- **2a** — один проход: скрытый старт → нижний стежок у L1 → подход к первой верхней точке L2 (операции 0…4).
- **2b** — один полный обход набора A, ряд 1: 8 стежков, замыкание через стартовый участок, парковка (операции 0…18).
- **2c** — последовательное шитьё: **+ B1** (нить B, ряд 1, линии B = A + 45°; операции 19…37) и **+ A2** (нить A из парковки, ряд 2, первый верх uwagake поверх ряда 1; операции 38…55). Уровни и E/X ряда 2 выводятся из занятости (model/spec.md G10–G14, D24–D27); над/под — хронология + uwagake; в изображении верхняя нить приподнята условно на 0,6·w на уровень стопки (D28, только картинка).
- **2.4 (#5)** — lift at crossings is mechanics: liftMode ideal by default (chord tents, bridges, the upper thread on the loaded lower thread; model/lift-spec.md v1.1, D46), lengths sphere / axis / lifted, validators V25–V27, K18, K19; the 0.6·w bump (D28) only in liftMode display. Numbers: samples/lift/numbers.md.
- Окраска по умолчанию — **по обходу** (A1, B1, A2, … — свои цвета, легенда); варианты: по набору, по длине нити, по типу участка.


## UI language (RU / EN)

The panel has a **RU | EN** toggle (top right). Choice is stored in `localStorage` key `temari.sim.locale` and mirrored as `?lang=ru|en`.

- Default: **ru**.
- Switching re-applies all `[data-i18n*]` strings and rebuilds the params form / captions / validators / legend without a full page reload (path op labels refresh via recompute).
- Code and comments stay English. EN UI prefers craft terms: *kiku*, *mari*, *NP*, *round* (A1/B1 circuit), *row* (row index), *set A/B*, *catch* / *pickup*, *hidden start*, *marking*, *pins*. See also `glossary.md` (ряд/круг).
- Strings still composed in Russian inside validator **value**/crit text and some path rule notes are listed as remaining Russian-only until those modules return message keys.

## Запуск

```
cd sim && python3 -m http.server 8765      # затем http://localhost:8765/
node test/run.mjs                          # безбраузерные тесты (из корня: node sim/test/run.mjs)
python3 tools/calc_reference.py            # эталон calc.py для кросс-проверки → data/calc_reference.json
cd tools && npm i && node screenshots.mjs  # скриншоты (playwright-core + системный google-chrome) → screenshots/
```
Состояние интерфейса хранится в URL, например
`index.html?C_mm=300&w_mm=1&stage=2b&k=10&view=oblique&t=1&color=type&zoom=2&focus=np`
(`t=1` прозрачный шар, `h=0` без скрытых участков, `lab=0` без подписей, `pins=0` без булавок, `dist=` дистанция камеры в мм).

## Архитектура (конвейер — чистая функция)

```
recipe.kiku-s8.json + параметры ──► base ──► marking ──► layout ──► rowPlan ──► path:A1 ──► validators
                                   (шар)    (S-N,m)     (булавки)   (замысел     (ops + сегменты   (V1–V21)
                                                                     рядов)      одной нити)
                                                                                     └──► render (только чтение)
```
| Модуль | Что делает |
|---|---|
| `data/recipe.kiku-s8.json` | рецепт как **замысел и операции иглы** (без координат и без ширины захвата): соглашения (ход, игла против хода, ⟂ линии, прямой канал, «вплотную к занятому»), слои, шаблон обхода, замыкание (TK-LITTLE), парковка, определения этапов 2a/2b/B1/A2, порядок работы A1 → B1 → A2, правила уровней ряда n ≥ 2 (belowPrevChannel, packThenPierce), над/под (laterOver, closingUnder); у каждого правила — источник и метка a/b/E |
| `src/params.js` | все входы как органы управления, группы а)–д) (шар, разметка, нить/материал, процесс, замысел), значение по умолчанию, основание, статус («источник», «по умолчанию, не измерено», «хранится, не используется», «замысел»), нормализация |
| `src/layers.js` | слои по порядку зависимостей; каждый несёт штамп-хэш своих входов и штампов родителей; `computeAll` всегда считает с нуля (нет кэшей между наборами параметров) |
| `src/path.js` | генератор пути: последовательное шитьё; **E/X выводятся** функцией `needleSides` из занятости у линии (нить разметки + уже уложенные нити на линии иглы); плечо — геодезическая или малый круг (bow); ряд n≥2 — рельс (концентрический малый круг); захват — хорда E→X; скрытый старт — хорды прямой иглы; перекресты с правилом над/под |
| `src/validators.js` | V1–V21 (ниже) |
| `src/display.js` | отображаемая геометрия (чистая функция, общая для рендера и V14): ось плеча на R + w/2, «нырок» в отверстия, пунктир захватов; скрытый старт по умолчанию **схемой** — дуга на w под поверхностью, режим «старт хордой» — как в модели |
| `src/tube.js` | меш трубки вдоль полилинии без three.js (параллельный перенос рамки); render.js оборачивает его в BufferGeometry, V14 проверяет его вершины |
| `src/geom.js` | сферическая геометрия (без three.js), в т. ч. независимая формула гаверсинуса для проверки длин |
| `src/render.js` | three.js: шар, разметка лентой ширины m, булавки (условно), нить — трубка диаметра w на поверхности (ось на R + w/2), скрытые участки — пунктир (из display.js), подсветка текущей операции поверх всего, подписи CSS2D |
| `src/main.js` | интерфейс: этап, шаг ⏮◀▶⏭, виды, прозрачность, окраска по u / по типу, длины, валидаторы, параметры + «Пересчитать» |
| `test/run.mjs` | тесты: 2a/2b, 2c (B1/A2 для 4 наборов, V15–V18, пересчёт 240↔300, сдвиг уровней A2 с w, уровни — правила, не числа), 6 наборов параметров, подобие, недопустимый дизайн, сдвиг E/X с w, чистота пересчёта, отсутствие ширины захвата, V14 и его отрицательный тест (нить поднята на 1 мм), проекция «крючков» у лимба, глубина схемы скрытого старта |
| `tools/calc_reference.py` | эталон из `samples/kiku-s8/calc.py` (numpy) — **независимая реализация** той же геометрии, 62 набора |

## Как выводятся точки иглы (решение D16, без «ширины захвата»)

`needleSides(s, линия k, уже уложенное)`: линия иглы — большой круг через точку линии, **перпендикулярный** ей
(игла прямая и ⟂ линии, OLY-BASIC «垂直に»). На ней собираются интервалы занятости: нить разметки [−m/2, m/2] и
следы уже уложенных нитей (пересечения и отверстия-концы, ширина следа w/sin угла). Кластер от нити разметки растёт,
пока зазор до соседней нити < w (рабочая нить туда не войдёт; prior #105 — игла между нитями, не сквозь).
E = правый край + w/2, X = левый край − w/2. Результат для S8 по умолчанию: обычный стежок ±(m + w)/2 = ±0,857 мм
(захват 1,714 мм — V9 сверяет с «about 1–2 mm» TK-LITTLE, «about 2mm» TK-KAGARI); замыкающий стежок на L0:
слева уже выходит стартовая нить ⇒ X = −(c0 + w) = −1,571 мм, захват 2,428 мм, стартовая нить внутри захвата.
Длина скрытого участка — хорда E→X (вычисляется, не задаётся). Смена w или m двигает E/X автоматически (тест).

### «Крючки» у полюса на виде «Косо» (скриншот 03) — не отрыв нити

Проверено численно (тест 6 в `test/run.mjs`): три плеча (к L2, L4, L5) переходят через лимб шара для этой камеры; сквозь прозрачный шар видна их задняя часть, и проекция дуги на сфере касается силуэта и поворачивает назад — отсюда «крючок». За силуэт выходит максимум 6,2 px при толщине трубки 6,0 px (кадр 1000 px, zoom 1,15), то есть только толщина трубки Ø w, лежащей на поверхности. На непрозрачном шаре (03c) эти участки уходят за край. Непрозрачность шара в прозрачном режиме поднята 0,28 → 0,40, чтобы задние участки были заметнее притушены.

## Ограничения (честно)

- Плечи — геодезические; фактическое положение в пределах конуса трения выбирает мастер (spec Ф3).
- Скрытый старт в модели — прямая хорда иглы (до 4,24 мм вглубь для 35 мм); на экране по умолчанию показан схемой у поверхности
  (подпись «схема … модель: прямая хорда»), флажок «старт хордой» показывает модель. На длины и валидаторы это не влияет.
- Нет толщины слоёв: в перекрестах трубки проходят друг сквозь друга; над/под записан топологически (V8, V10).
- Направление скрытого старта в источниках не указано — выбор модели [E] (к биссектрисе предыдущего сектора на уровне
  булавок, два прохода в линию); влияет только на скрытую геометрию.
- Диаметр булавки не моделируется: нижний стежок ряда 1 — ровно на уровне булавки («just below pin», GT14).
- Сечение нити круглое диаметра w только в рендере и в V8; h/w, μ, T, сжимаемость хранятся, но геометрией не используются.
- Вариант Olympus TM-7 (старт снизу, одна нить на оба набора, 16 делений, слабина) не смешивается с GT14; из него
  доступен только способ закрепления OLY-BASIC.
